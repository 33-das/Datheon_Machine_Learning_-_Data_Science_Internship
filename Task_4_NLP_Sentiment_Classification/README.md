# Task 4: NLP Sentiment Classification on Customer Reviews

## Project Overview
This project implements a sentiment classification system using Natural Language Processing and machine learning.

## Technologies
- Python
- Pandas
- NLTK
- Scikit-learn
- TF-IDF
- Google Colab

## Machine Learning Models
1. Multinomial Naive Bayes
2. Logistic Regression

## Evaluation
Both classifiers achieved 44.44% accuracy in the three-fold cross-validation experiment.

## Limitation
The dataset contains only nine labelled positive/negative reviews. Therefore, the results are exploratory and are not reliable performance benchmarks.
